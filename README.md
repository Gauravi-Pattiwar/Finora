# Finora - Finance + Aura

Finora is a browser-based financial health advisory prototype for tracking
income, expenses, budgets, savings, debt, and financial goals. It provides
visual dashboards, AI and rule-based insights, and downloadable reports.

## Tech stack

- HTML, CSS, and vanilla JavaScript
- Node.js and Express for local API routes
- MongoDB for account and application data
- Vercel serverless functions for deployment
